## Getting Started

### Requirements

- A C++ compiler such as `g++` or `clang++`
- A terminal or a C++ IDE (for example, Visual Studio Code)

### Compile and run a program

Each `.cpp` file is a standalone example. From the repository root, compile a program by providing its path:

```bash
g++ "Programs/C++ Fundamentals/input_and_addition.cpp" -o program
./program
```

Replace the source path with the program you want to run. On Windows, run the generated executable as `program.exe`.
